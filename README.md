# Медиакоми 🏠

Мобильная игра-угадайка по реальным объявлениям недвижимости: смотришь фотографии
квартиры из Республики Коми, двигаешь бегунок — называешь цену, а после нажатия
«Оценить» сравниваешь её с настоящей ценой объявления на Авито.

## Экраны

1. **Старт** — название сервиса, краткие правила и балльная система, кнопка «Запустить игру».
2. **Лот** — галерея фотографий (свайп или стрелки), бегунок цены, кнопка «Оценить», прогресс-бар раундов.
3. **Результат лота** — реальная цена, разница с твоей, баллы и ссылка на исходное объявление.
4. **Итоги** — сумма баллов из 1000, статистика и вердикт: *жадный студент* / *адекватный квартирант* / *транжира*.

## Баллы

Ошибка считается относительно реальной цены: `|твоя цена − реальная| / реальная`.

| Ошибка | Баллы |
|---|---|
| до 5% | 100 |
| до 10% | 85 |
| до 20% | 65 |
| до 35% | 40 |
| до 60% | 20 |
| больше 60% | 10 |

Вердикт считается по среднему отклонению за игру: ставки стабильно **ниже** реальных
цен — «жадный студент», **выше** — «транжира», в среднем совпали (±10%) — «адекватный квартирант».

## Локальный запуск

Сайт полностью статический, сборка не нужна:

```bash
cd mediakomi
python3 -m http.server 8000
# открыть http://localhost:8000
```

или просто открыть `index.html` в браузере.

## Публикация на GitHub Pages

```bash
cd mediakomi
git init && git add . && git commit -m "Медиакоми: игра-угадайка цен квартир"
gh repo create mediakomi --public --source=. --push
```

Затем в настройках репозитория: **Settings → Pages → Build and deployment →
Source: Deploy from a branch → Branch: main, папка / (root) → Save**.
Через минуту игра будет доступна по адресу `https://<логин>.github.io/mediakomi/`.

## Данные и обновление

Все лоты берутся из выгрузки объявлений Авито (г. Инта) — файл `data.js`,
фотографии лежат локально в `assets/img/` и сжаты для мобильных экранов.
В игру попадают только лоты, у которых живы минимум два фото (объявления
без фото из выгрузки отбрасываются, цены в выгрузке соответствуют активным
объявлениям на момент сбора данных).

Пересобрать данные после новой выгрузки CSV:

```bash
python3 tools/build_data.py
```

Скрипт читает `data komi - Лист1.csv` из родительской папки, скачивает фото
(недоступные отбрасывает) и перегенерирует `data.js`.
